\## 1. Минимум трёх чисел (`minimum.py`)



Программа находит наименьшее число среди трёх введённых пользователем целых чисел, используя только последовательные проверки.



\### Логика работы:

1\. Программа запрашивает у пользователя три целых числа.

2\. Программа принимает первое число за текущий минимум (`minimum = a`).

3\. Далее идут последовательные проверки:

&#x20;  \* Если второе число меньше текущего минимума, оно становится новым минимумом.

&#x20;  \* Если третье число меньше текущего минимума, оно перезаписывает переменную `minimum`.

4\. Данный алгоритм корректно обрабатывает ситуации, когда среди введённых чисел есть равные или все три числа идентичны.



\---



\## 2. Простой калькулятор (`calculator.py`)



Программа принимает два вещественных числа и математический оператор, после чего выводит результат вычисления, округлённый до двух знаков после запятой.



\### Логика работы:

1\. Пользователь вводит два числа (с плавающей точкой) и символ операции: `+`, `-`, `\*` или `/`.

2\. Конструкция `if-elif-else` сопоставляет введённый символ:

&#x20;  \* \*\*Математические операции:\*\* Выполняется стандартное сложение, вычитание или умножение.

&#x20;  \* \*\*Деление с защитой:\*\* Перед выполнением деления программа проверяет делитель. Если второе число равно `0`, вычисления блокируются и выводится сообщение: `Деление на ноль запрещено`.

&#x20;  \* \*\*Ошибка ввода:\*\* Если введён любой другой символ (например, `%`, `^`, `а`), программа переходит в ветку `else` и выводит: `Неизвестная операция`.

\## 3. Принадлежность точки контуру (`point.py`)



Программа проверяет, попадают ли введённые координаты (x, y) внутрь или на границу прямоугольной области, заданной диапазонами: 0 ≤ x ≤ 5 и 0 ≤ y ≤ 3.



\### Логика работы:

1\. Пользователь вводит координаты `x` и `y` (поддерживаются как целые, так и дробные значения).

2\. С помощью логического оператора `and` проверяется \*\*одновременное\*\* выполнение двух условий:

&#x20;  \* Координата `x` должна быть не меньше 0 и не больше 5.

&#x20;  \* Координата `y` должна быть не меньше 0 и не больше 3.

3\. Поскольку операторы сравнения используют `求=` и `<=` (нестрогое сравнение), точки, лежащие ровно на линиях x=0, x=5, y=0, y=3, считаются частью фигуры.

4\. Если оба условия верны, выводится `Внутри или на границе`. Если хотя бы одно условие нарушено — выводится `Снаружи`.

\## Инструкция по запуску



Для запуска скриптов вам понадобится установленный интерпретатор \*\*Python 3.x\*\*.



Откройте терминал (или командную строку), перейдите в папку с файлами и выполните нужную команду:



```bash

\# Запуск поиска минимума

python minimum.py



\# Запуск калькулятора

python calculator.py



\# Запуск проверки координат

python point.py

```
